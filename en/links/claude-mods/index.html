Claude Code now has mods. It’s still a test mode — the official launch is promised in the coming weeks — but you can already try it.

How to turn them on

Add this once to ~/.claude/settings.json:

{ "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }

Or launch Claude like this: CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude

Arcade — 9 games while Claude works

Tetris, Snake, Doom, 2048, Minesweeper, four more, and a pet that grows with how much you get done.

claude plugin marketplace add sezaakgun/cc-arcade
claude plugin install cc-arcade@cc-arcade

When the answer is ready, the game pauses itself and says “Claude is done”.

github.com/sezaakgun/cc-arcade

Breathing — inhale for five, exhale for six while the answer loads

claude plugin marketplace add halluton/Mindful-Claude
claude plugin install mindful-claude@mindful-claude

github.com/halluton/Mindful-Claude

The third mod

The third mod hides sensitive data (passwords, emails) on your screen. It’s a demo by Anthropic itself, so there’s no “install” button. But you can ask for it in one sentence — “make a plugin that hides numbers and emails on the screen and shows them when I hover” — and Claude builds it for you. All the official demos and the discussion are here: github.com/anthropics/claude-code/issues/91870
