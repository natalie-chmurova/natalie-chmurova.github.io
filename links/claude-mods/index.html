Моды для Claude Code

Как включить моды и какие поставить первыми — аркада и дыхание, пока Claude думает

  • Обсуждение и демо от Anthropicgithub.comкак всё устроено, официальные демо, включая мод, который прячет пароли с экрана
  • cc-arcadegithub.comдевять игр, пока Claude работает; когда ответ готов, игра сама встаёт на паузу
  • Mindful Claudegithub.comвдох на пять, выдох на шесть, пока идёт ответ
  • Каталог модовgithub.comпокемоны над строкой запроса, парусник вместо логов, браузер внутри терминала

Это для тех, у кого Claude Code уже стоит. Claude Code — версия Claude для терминала, ей пользуются те, кто работает с кодом. Если ты никогда не открывала терминал, дальше можно не читать: ролик был не про «поставь себе», а про то, что нейросети перестали быть готовыми программами.

Как включить

Один раз добавить в файл ~/.claude/settings.json:

{ "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }

Или запускать так: CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude

Поставить аркаду

claude plugin marketplace add sezaakgun/cc-arcade
claude plugin install cc-arcade@cc-arcade

Поставить дыхание

claude plugin marketplace add halluton/Mindful-Claude
claude plugin install mindful-claude@mindful-claude

Пока это тестовый режим, официальный запуск обещают в ближайшие недели.
