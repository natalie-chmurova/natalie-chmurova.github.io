В Claude Code появились моды. Пока это тестовый режим, официальный запуск обещают в ближайшие недели, но попробовать можно уже сейчас.

Как включить

Один раз добавить в файл ~/.claude/settings.json:

{ "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }

Или запускать так: CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude

Аркада — 9 игр, пока Claude работает

Тетрис, змейка, Doom, 2048, сапёр, ещё четыре и питомец, который растёт от того, сколько ты сделал.

claude plugin marketplace add sezaakgun/cc-arcade
claude plugin install cc-arcade@cc-arcade

Когда ответ готов, игра сама встаёт на паузу и пишет «Claude is done».

Дыхание — вдох на пять, выдох на шесть, пока идёт ответ

claude plugin marketplace add halluton/Mindful-Claude
claude plugin install mindful-claude@mindful-claude

Третий мод

Третий мод прячет sensitive данные (пароли, почты) с экрана — это демонстрация самой Anthropic, кнопки «установить» у него нет. Но его можно попросить одной фразой «сделай плагин, который прячет цифры и почты на экране и показывает их, когда навожу мышку» — и Claude собирает его сам. Все официальные демо и обсуждение здесь: github.com/anthropics/claude-code/issues/91870
